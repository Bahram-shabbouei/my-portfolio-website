## 🎯 Projektübersicht

**Mein Portfolio** ist eine moderne, interaktive Single-Page-Application (SPA), die meinen beruflichen Werdegang, technische Fähigkeiten und abgeschlossene Projekte präsentiert. Die Anwendung wurde mit Fokus auf **Benutzererfahrung**, **Responsive Design** und **Leistungsoptimierung** entwickelt.

### Ziele dieser Anwendung

| Ziel | Beschreibung |
|------|--------------|
| **Professionelle Präsentation** | Vorstellung meiner Person, Fähigkeiten und Projekte in ansprechendem Design |
| **Interaktive Benutzererfahrung** | Dynamische Elemente wie Timeline, Fortschrittsbalken und Animationen |
| **Kontaktaufnahme erleichtern** | Zweistufiges Kontaktformular für einfache Kommunikation |
| **Technische Demonstration** | Showcase moderner Frontend-Technologien (React, TypeScript, Vite) |

### 🎨 Design-Philosophie

- **Clean & Minimalistisch:** Fokus auf Inhalte mit klarer Typografie
- **Farbpsychologie:** Professionelle Farbpalette mit Akzentfarben für Call-to-Actions
- **Barrierefreiheit:** Kontrastreiche Farben und semantisches HTML für Screenreader
- **Mobile First:** Optimiert für alle Bildschirmgrößen
